## 1. プロジェクトの背景と目的

### 課題
歯科医院では、新人スタッフの教育や業務マニュアルの作成に多大な時間と労力がかかっている。
- 手順書の作成に **数時間〜数日** かかる
- 動画教材はあるが、**文書化されていない**
- スタッフごとに理解度が異なり、**統一されたマニュアルがない**

### 解決策
**動画をアップロードするだけで、AIが自動的にマニュアルを生成する。**

歯科治療や作業の動画を入力するだけで、Google Gemini AI が映像を解析し、
ステップごとの手順書を **Word / PDF / PowerPoint / 画像カード** として自動出力する。

### 期待される効果
- マニュアル作成時間を **90%削減**（数時間 → 数分）
- 新人教育の **標準化**
- 教材の **多様なフォーマット対応**（紙・スライド・SNS投稿用画像）

## 4. ユーザーフロー（使い方）

### Step 1: アプリ起動
```bash
cd dental_manual_app
pip3 install -r requirements.txt
streamlit run app.py
```
ブラウザが自動的に開き、アプリが表示される。

### Step 2: API設定
左サイドバーで Google Gemini API キーを入力。
（取得先: https://aistudio.google.com/app/apikey）

### Step 3: 動画入力
2つの方法から選択：
- **ファイルアップロード**: MP4/MOV/AVIファイルをドラッグ＆ドロップ
- **YouTubeリンク**: URLを貼り付けてダウンロード

### Step 4: AI分析
「🚀 分析開始」ボタンをクリック。
AIが動画フレームを自動抽出・分析し、手順書の原稿を生成。

### Step 5: 編集
「✏️ 編集・出力」タブでAI生成結果を確認・修正。
- タイトル・概要の編集
- 各ステップの手順・注意事項の修正
- 必要な器具リストの編集

### Step 6: 出力・ダウンロード
4つの出力形式から必要なものを選択して生成・ダウンロード。

## 7. リスクと対策

| リスク | 影響度 | 対策 |
|--------|--------|------|
| Gemini APIの仕様変更 | 高 | google.genai パッケージへの早期移行 |
| 動画分析の精度不足 | 中 | プロンプト改善、モデル選択の最適化 |
| 個人情報を含む動画の取り扱い | 高 | ローカル実行を推奨、データ保持ポリシー策定 |
| YouTube動画の著作権問題 | 中 | 自院で撮影した動画の利用を推奨 |
| 日本語フォントの表示問題 | 低 | 日本語フォント埋め込み対応 |
