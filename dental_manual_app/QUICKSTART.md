# 🚀 クイックスタートガイド - 5分で始める

## 📱 本番環境（すぐ使える）

### ステップ1: アクセス
https://dental-manual-generator.streamlit.app/

### ステップ2: APIキー設定（初回のみ）
1. https://ai.google.dev/ にアクセス
2. 「Get API Key」をクリック
3. APIキーをコピー
4. アプリの左サイドバーに貼り付け

### ステップ3: 動画アップロード
**方法A: ファイル直接アップロード**（最大200MB）
- MP4/MOV/AVI形式に対応

**方法B: YouTube**
- YouTubeのURLを貼り付け
- 「ダウンロード」ボタンをクリック

**方法C: Google Drive**（10GB以上もOK）
1. Google Driveに動画をアップロード
2. 右クリック → 「共有」→「リンクを知っている全員」
3. リンクをコピーしてアプリに貼り付け

### ステップ4: 分析開始
1. 「🚀 分析開始」ボタンをクリック
2. 20-30秒待つ（AI分析中）
3. ✅ 完了！

### ステップ5: マニュアル生成
1. 「✏️ 編集・出力」タブに移動
2. 必要に応じて内容を編集
3. 好きな形式をクリック:
   - 📄 Word（.docx）
   - 📕 PDF
   - 📊 PowerPoint（.pptx）
   - 🖼️ 画像カード（SNS用）


## 📸 スクリーンショット機能（NEW!）

### 自動抽出される内容
- 動画から**8枚**のスクリーンショットを自動抽出
- AIが各ステップに最適な画像を選択
- タイムスタンプ付きで表示

### 確認方法
1. 分析完了後、「分析結果プレビュー」をチェック
2. 「編集・出力」タブで各ステップを開く
3. ステップの先頭に画像とタイムスタンプが表示される

### 生成されたドキュメント内
- **Word**: 各ステップに画像が埋め込まれる
- **PDF**: ステップタイトルの下に画像
- **PowerPoint**: スライド右側に画像配置

## 🐛 トラブルシューティング（1分解決）

### エラー: 「APIキーが無効」
→ https://ai.google.dev/ で新しいAPIキーを取得

### エラー: 「動画を読み込めません」
→ ファイル形式を確認（MP4/MOV/AVIのみ対応）

### スクリーンショットが表示されない
→ ブラウザをリフレッシュ（Ctrl+R / Cmd+R）

### Google Driveダウンロードが失敗
→ 共有設定が「リンクを知っている全員」になっているか確認

### ページが重い
→ ブラウザのキャッシュをクリア

## 📥 ダウンロード後の使い方

### Word (.docx)
- Microsoft Word、Google Docs、LibreOfficeで開ける
- 編集・印刷が自由
- 社内共有に最適

### PDF
- どのデバイスでも表示同じ
- 印刷用に最適
- 患者配布資料に

### PowerPoint (.pptx)
- スタッフ研修に使える
- プロジェクター投影に最適
- アニメーション追加可能

### 画像カード
- SNS投稿用（Instagram、X等）
- サイズ: 1080×1080px
- スマホで閲覧しやすい
