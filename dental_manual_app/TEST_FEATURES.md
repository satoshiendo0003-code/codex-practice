# スクリーンショット埋め込み機能 - テストチェックリスト

## 🎯 新機能概要

動画分析時に自動的にスクリーンショットを抽出し、生成されるマニュアル（Word/PDF/PowerPoint）に埋め込む機能。

## ✅ テストチェックリスト

### Phase 1: フレーム抽出テスト

- [ ] **動画アップロード成功**
  - 手順: ファイルアップロード → MP4動画を選択
  - 期待結果: ✅ 動画をアップロードしました

- [ ] **フレーム抽出確認**
  - 手順: 分析開始ボタンをクリック
  - 期待結果: 「動画からフレームを抽出中...」メッセージ表示
  - 確認: `output/frames/YYYYMMDD_HHMMSS/` ディレクトリが作成される
  - 確認: frame_0.jpg ～ frame_7.jpg が保存される

- [ ] **プレビュー表示**
  - 手順: 分析完了後、「分析結果プレビュー」セクションを確認
  - 期待結果: 「📸 抽出されたスクリーンショット」セクションに3枚表示
  - 確認: 各画像に「ステップ X」のキャプション

### Phase 2: UI表示テスト

- [ ] **編集画面でのスクリーンショット表示**
  - 手順: 「編集・出力」タブ → 各ステップのexpanderを開く
  - 期待結果: ステップの先頭にスクリーンショット画像が表示
  - 確認: 画像の下に「⏱️ タイムスタンプ: X:XX」が表示

- [ ] **タイムスタンプ精度確認**
  - 手順: 複数のステップでタイムスタンプを確認
  - 期待結果: 時系列順に並んでいる（0:15 → 1:30 → 2:45...）
  - 確認: 動画の長さと整合性がある

### Phase 3: ドキュメント生成テスト

#### Word (.docx)

- [ ] **Word生成成功**
  - 手順: 📄 Wordボタンをクリック
  - 期待結果: ✅ Wordの生成が完了しました

- [ ] **画像埋め込み確認**
  - 手順: ダウンロードしたWordファイルを開く
  - 確認項目:
    - [ ] 各ステップのタイトル下に画像が挿入されている
    - [ ] 画像サイズが適切（4.5インチ幅）
    - [ ] 画像の下に説明文が続いている
    - [ ] 画像がぼやけていない（解像度十分）

#### PDF

- [ ] **PDF生成成功**
  - 手順: 📕 PDFボタンをクリック
  - 期待結果: ✅ PDFの生成が完了しました

- [ ] **画像埋め込み確認**
  - 手順: ダウンロードしたPDFファイルを開く
  - 確認項目:
    - [ ] 各ステップのタイトル下に画像が挿入されている
    - [ ] 画像サイズが適切（4×3インチ）
    - [ ] ページレイアウトが崩れていない
    - [ ] 画像とテキストのバランスが良い

#### PowerPoint (.pptx)

- [ ] **PowerPoint生成成功**
  - 手順: 📊 PowerPointボタンをクリック
  - 期待結果: ✅ PowerPointの生成が完了しました

- [ ] **画像配置確認**
  - 手順: ダウンロードしたPowerPointファイルを開く
  - 確認項目:
    - [ ] 各スライドの右側に画像が配置されている
    - [ ] 左側にテキスト（説明、重要ポイント）が配置
    - [ ] 画像サイズ: 4×3インチ
    - [ ] スライドレイアウトがバランス良い
    - [ ] 画像がある場合とない場合で適切にレイアウト調整

### Phase 4: データ永続化テスト

- [ ] **セッション状態保存**
  - 手順: ブラウザをリフレッシュ
  - 期待結果: 「前回作業していた状態を復元しました」トースト表示
  - 確認: スクリーンショットが保持されている

- [ ] **編集後の画像パス保持**
  - 手順: ステップのタイトルや説明を編集 → Word生成
  - 期待結果: 編集後も同じスクリーンショットが埋め込まれる
  - 確認: `image_path`, `timestamp`, `frame_index`が保持される

### Phase 5: エッジケーステスト

- [ ] **短い動画（< 10秒）**
  - 期待結果: フレーム数が少なくても正常に動作
  - 確認: 最低1枚は抽出される

- [ ] **長い動画（> 10分）**
  - 期待結果: 8フレームが均等に抽出される
  - 確認: タイムスタンプが適切に分散

- [ ] **フレームなしのステップ**
  - 状況: AIがframe_indexを指定しなかった場合
  - 期待結果: 最初のフレーム（frame_0）がデフォルトで使用される
  - 確認: ドキュメント生成でエラーが出ない

- [ ] **画像ファイルが削除された場合**
  - 手順: `output/frames/`を手動削除 → ドキュメント生成
  - 期待結果: エラーが出ず、画像なしでドキュメント生成される
  - 確認: os.path.exists()チェックが機能

### Phase 6: パフォーマンステスト

- [ ] **フレーム抽出時間**
  - 動画長: 5分
  - 期待時間: < 10秒
  - 確認: スピナーメッセージが適切に表示

- [ ] **Gemini API呼び出し**
  - 期待時間: < 30秒（8フレームアップロード + 分析）
  - 確認: タイムアウトしない

- [ ] **ドキュメント生成時間**
  - Word/PDF/PowerPoint各形式
  - 期待時間: < 5秒
  - 確認: 画像挿入による遅延が許容範囲内

## 🐛 既知の問題

### 警告（Warning）レベル

- **google.generativeai deprecation警告**
  - 内容: "All support for google.generativeai package has ended"
  - 影響: 現在は動作するが将来サポート終了
  - 対応予定: google.genaiパッケージへの移行

### 改善予定

- フレーム抽出数が固定（8枚）→ UI設定可能にする
- 画像サイズが固定 → カスタマイズオプション追加
- フレーム選択がAI自動のみ → 手動選択オプション

## ✅ テスト完了の定義

以下すべてが満たされた場合、機能テスト完了とする：

1. ✅ Phase 1-3のすべての項目がチェック済み
2. ✅ Word/PDF/PowerPointで画像が正しく埋め込まれている
3. ✅ タイムスタンプが正確に表示される
4. ✅ エッジケース（Phase 5）で致命的エラーが出ない
5. ✅ パフォーマンス（Phase 6）が許容範囲内
