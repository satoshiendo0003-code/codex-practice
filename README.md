# アンチグラビティアプリ

Googleのアンチグラビティエフェクトを再現したWebアプリケーションです。

## 説明

マウスカーソルを動かすと、画面上のパーティクルが重力に反して動きます。
カーソルに近づくとパーティクルが反発する、美しいインタラクティブなエフェクトを楽しめます。

## 修正した起動問題

以下の問題を修正しました：

### 問題点
1. **DOMContentLoadedイベントを待っていない**: HTMLが完全に読み込まれる前にJavaScriptが実行されていた
2. **container要素の取得エラー**: `this.container`ではなく`container`に代入していた（`this`が抜けていた）
3. **nullチェックの欠如**: containerがnullの場合の処理がなかった

### 修正内容
- `antigravity.js:14` - `this.container`への正しい代入
- `antigravity.js:17-20` - nullチェックとエラーハンドリングを追加
- `antigravity.js:96-99` - DOMContentLoadedイベントリスナーで初期化を待機

## 実行方法

ブラウザで`index.html`を開いてください。

## 機能

- 50個のカラフルなパーティクルが画面上を動きます
- マウスカーソルに近づくとパーティクルが反発します
- 画面端でパーティクルが反対側から出現します（ラップアラウンド効果）
